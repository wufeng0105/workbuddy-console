# Design System: workbuddy-console 控制台（需求侧重构版）

**Project ID:** 15922030281254393504
**语言：** 全部 UI 文案简体中文 ｜ **主题：** 浅色 ｜ **设备：** DESKTOP

## 1. 视觉主题与氛围

**清晰的任务工作台**。与「工业仪表」式的旧版不同，本版把每个用户任务摆成一张大卡片，任务内部是一条带步骤条的向导。视觉仍然克制（无插画、无渐变、颜色只用于状态），但更**透气、友好、有引导感**：卡片圆角更大、留白更多、每屏只有一个焦点任务。情绪关键词：**清楚、踏实、被引导**。

## 3. 排版规则

- 全站 **Inter**，简体中文回退 PingFang SC / Microsoft YaHei
- 层级：页标题 22px/700 → 区块标题 15px/600 → 卡片标题 14px/600 → 正文 13px/400 行高 1.65 → 辅助 12px
- **数字、路径、把手 id、sha256、token 数一律等宽字体**（JetBrains Mono 栈），这是数据可信度的视觉来源
- 全部文案简体中文；操作按钮用动词短语（「应用并验证」「切换到这一档」）

## 4. 组件样式

- **任务卡（本版主角）**：大白卡（8px 圆角、1px 发丝边、16-20px 内边距），含图标位 + 标题 + 一句话描述 + 右下「进入 →」；悬停时边框转行动蓝
- **步骤条（Wizard Stepper）**：横向三步「编辑 → 预览差异 → 应用并验证」；已完成步骤绿底 ✓，当前步骤蓝底数字，未到步骤灰；常驻工作面顶部
- **三态徽章**：生效（绿底绿边绿字 ✓）/ 未生效（红底红边红字 ✕）/ 无法判定（黄底黄边黄字 ?）——**三件套缺一不可，无法判定永不显示为成功**
- **双面可信度卡**：绿卡（可可靠验证）与黄卡（无法保证）并排，徽章 + 一句话边界说明
- **Diff 块**：等宽字体；新增行 `#e7f7f0` 底 `#0a6b4c` 字带 `+`；删除行 `#fdeeef` 底 `#a02634` 字带 `-`；上下文行灰
- **按钮**：主按钮行动蓝实底白字 8px 圆角；次按钮白底发丝边；危险操作红字白底；无渐变无投影
- **状态头（导航条右侧）**：WorkBuddy 运行状态圆点（绿/灰）+ 版本号（等宽）

## 5. 布局原则

- **顶部横向导航条**（56px，白底发丝线下边）：左「WorkBuddy 控制台」标识 → 中部五个域标签（总览 / 个性化 / 档位 / 审批 / 守护 / 边界中的当前五域）→ 右侧运行状态徽章
- 内容区**居中，max-width 1200px**，页面纵向滚动；卡片网格间距 16-20px
- 每页结构 = 页头（任务名 + 一句话）→ 步骤条（向导类页面）→ 卡片/内容主体 → 页尾诚实边界说明
- 单屏一个焦点任务；相关信息以次级卡片折叠在主卡下方
