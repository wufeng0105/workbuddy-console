# web/ —— 前端控制台

> 三栏浅色仪表盘，**原生 ESM，不引构建链**（本地特权工具：依赖树越小越容易审计）。
> 启动：`node src/cli.mjs serve`（仅监听 127.0.0.1，令牌随启动生成）。
> 控制台 URL 会落在 `<用户数据目录>/state/console-url.txt` —— **令牌每次启动都变**，从那里复制。

## 结构

```
┌─────────┬──────────────┬───────────────────────────┐
│ 域导航   │ 列表          │ 工作面                     │
│ 76px    │ 296px        │ 自适应                     │
└─────────┴──────────────┴───────────────────────────┘
```

## 五个工作面

| 域 | 内容 |
|---|---|
| **定制** | 18 个把手分 4 组（按心智，不按数据结构）。现状表 → 编辑器 → 差异预览 → 应用并验证 → 还原 |
| **审批** | 双面**用颜色区分可信度**：绿「可可靠验证」/ 黄「无法保证」+ 三档位 |
| **档位** | 采集 / 预览切换 / 切换（事务）/ 验证 / 删除 |
| **守护** | 升级漂移逐条状态 + 备份还原 + 操作记录台账 |
| **边界** | 六条"做不到"的事，每条附证据出处 |

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 挂载点（只剩 `<div id="app">`） |
| `core.js` | 令牌 / API 封装 / DOM 工具 / 格式化 / 分组与边界常量 |
| `app.js` | 三栏主应用，按域切换工作面 |
| `style.css` | 浅色仪表盘设计令牌（颜色**只用于标示状态**） |

## 编辑器按把手类型分流

| 把手类型 | 编辑器 |
|---|---|
| 身份 / 风格文件（文本） | 大文本编辑器，带字符计数与**超限截断提示** |
| `toneStyle`（枚举锁死） | 下拉选择 |
| `rules.*`（规则矩阵） | **结构化操作**：选「从什么改成什么」+ 勾选作用动作，不手改 JSON |

## 差异化警告（不是套话）

界面按把手的真实属性给出不同警告：

- 厂商文件 → 「升级可能覆盖它；写入需显式确认」
- `IDENTITY.md` → 「专家模式下不注入 —— 切档位时"名字"会静默消失」
- 内容超限 → 「超出部分静默丢弃」并按截断后文本算期望增量
- 非生效档位 → 「改它不会影响任何请求」
- 需停机把手 → 「要求 App 已退出才能写入」

## 硬约束（已落实）

- 前端**永不直接触碰文件系统**——一切经本地服务端 `/api/*`
- 鉴权：仅回环 + 随机端口 + 一次性 token（`X-WBC-Token`）；**绝不监听 `0.0.0.0`**
- 厂商文件写入必须**显式勾选确认**（铁律 5），服务端二次校验
- 三态**不得合并**：`undetermined`（无法判定）渲染为黄色，**绝不显示成成功**（铁律 6）
- 无重放包时，定制状态标「未知」而**不猜**（铁律 3）
