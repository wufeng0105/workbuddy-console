# web/ —— 前端静态页

> 单页控制台，**原生 ESM，不引构建链**（本地特权工具：依赖树越小越容易审计）。见 `../docs/framework.md` 第九节。
> 启动：`node src/cli.mjs serve`（仅监听 127.0.0.1，令牌随启动生成），控制台 URL 同时落在 `<用户数据目录>/state/console-url.txt`。

## 已实现（P0c）

| 文件 | 内容 |
|---|---|
| `index.html` | 骨架：顶部体检状态 + 左侧把手列表 + 右侧详情 |
| `app.js` | 把手列表 / 现状 / 编辑器 / 差异预览 / 应用 / 验证 / 备份还原 |
| `style.css` | 设计令牌与三态配色（无外部资源） |

## 硬约束（已落实）

- 前端**永不直接触碰文件系统**——一切经本地服务端 `/api/*`
- 鉴权：仅回环 + 随机端口 + 一次性 token（`X-WBC-Token`）；**绝不监听 `0.0.0.0`**
- 厂商文件写入必须**显式勾选确认**（铁律 5），由服务端二次校验
- 三态**不得合并**：`undetermined`（无法判定）渲染为黄色，**绝不显示成成功**（铁律 6）
