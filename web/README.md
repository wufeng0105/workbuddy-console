# web/ —— 前端静态页

> 单页控制台，**原生 ESM，不引构建链**（本地特权工具：依赖树越小越容易审计）。见 `../docs/framework.md` 第九节。

## 待实现（P0）

| 区块 | 内容 |
|---|---|
| **把手面板** | 每个把手：现状 / 差异预览 / 备份 / 应用 / 验证结论 / 还原 |
| **验证视图** | 三态显示（生效 / 未生效 / **无法判定**），禁止把"无法判定"渲染成成功 |
| **漂移视图** | 锚点失效 / 值已变 / 厂商已还原 三类告警 |
| **审计台账** | 每次写入：触发者、时间、manifest 引用、验证结论 |

## 硬约束

- 前端**永不直接触碰文件系统**——后端是唯一持有写权限的进程
- 鉴权：仅回环 + 随机端口 + 一次性 token；**绝不监听 `0.0.0.0`**
- 厂商文件写入必须**显式二次确认**（铁律 5）
